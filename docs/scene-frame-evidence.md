## In-game precedent

The deprecated `MuvluvModMod` plugin performed the same rewrite against this
title: a prefix on `EpisodeService.DownloadSceneFrameMasters` captured the scene
id, then a prefix on `ScenarioController.GenerateFrames` parsed each
`ConfigurationJson` and reassigned `Phrase.SpeakerName`, `Phrase.TeamName`, and
`Phrase.Text`. This confirms the seam is stable and sufficient on this build.
